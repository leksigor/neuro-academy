# NeuroAcademy

Интерактивный сайт по обучению нейросетям.

Репозиторий: https://github.com/leksigor/neuro-academy

Чтобы сайт открылся в интернете:
1. Откройте https://github.com/leksigor/neuro-academy/settings/pages
2. Source: Deploy from a branch
3. Branch: main, folder: / (root)
4. Save

Через 1–2 минуты сайт будет здесь:
https://leksigor.github.io/neuro-academy/
